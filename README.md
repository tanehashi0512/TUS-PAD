# TUS-PAD Video Examples

https://tanehashi0512.github.io/TUS-PAD/

Static webpage showing representative videos from the three newly collected
TUS-PAD scenarios.

Place these MP4 files in `videos/`:

- `metronome_norm1.mp4`
- `metronome_ano1.mp4`
- `ski_norm1.mp4`
- `ski_ano1.mp4`
- `gym_norm1.mp4`
- `gym_ano1.mp4`
- `gym_ano2.mp4`

Upload `index.html`, `style.css`, and the `videos` folder to the root of the
GitHub Pages repository.
