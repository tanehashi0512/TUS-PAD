# TUS-PAD Video Examples

A static research webpage for representative normal/abnormal video examples.

## Add videos

Place MP4 files in `videos/` using these names:

- clock_normal.mp4 / clock_abnormal.mp4
- pendulum_normal.mp4 / pendulum_abnormal.mp4
- sliding_block_normal.mp4 / sliding_block_abnormal.mp4
- rotation_normal.mp4 / rotation_abnormal.mp4
- metronome_normal.mp4 / metronome_abnormal.mp4
- ski_normal.mp4 / ski_abnormal.mp4
- gym_normal.mp4 / gym_abnormal.mp4

## Publish with GitHub Pages

1. Create a GitHub repository.
2. Upload `index.html`, `style.css`, and the `videos` folder.
3. Open repository Settings → Pages.
4. Select deployment from the main branch/root.
5. Use the resulting Pages URL in the paper.

Before submission, verify that the public URL works in a logged-out/private browser.
